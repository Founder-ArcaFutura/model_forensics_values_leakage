# Protocol audit: invalidated choice pilot

The raw records in this directory are preserved, but this run is invalid for
the label-versus-welfare contrast. The first implementation varied the
GOOD-label side without applying the existing moral-inversion protocol's
complementary above/below outcome mapping. This was found in an audit after
the 80 calls completed. The run is not used in the final interpretation.

The corrected mapping is covered by regression tests and was run as the
separate protocol `pretrained-donation-bet-choice-category-v2` in
`../pretrained_donation_bet_pilot_choice_category_v2/`.
